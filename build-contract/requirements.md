# Normative prototype requirements

Version 1.0.0, public-sanitized distribution. [contract.json](contract.json) is the machine-readable source of truth. All 60 requirements remain proposed; none is claimed implemented. See [decisions](decisions-and-assumptions.md) and [open review findings](review-findings.md).

| R002 | Access | Gate the feature off by default; disabled or ineligible users/events must neither expose the entry nor initialize VDO.Ninja, camera/mic or a publisher. | prototype-default | T002, T037 |

| R018 | Audio | Provide conversational return excluding each participant own mic and delayed buyer playback; prevent duplicate host mic capture, duplicate audio playback and doubled program audio. | user-direction | T010, T035 |

| R020 | Removal | On host removal, exclude guest video/audio at program ingress within 1000 ms, invalidate its admission/lease, and return to a host-only program without restarting output; account for downstream viewer delay separately. | prototype-default | T011, T029 |
| R021 | Departure | Guest leave stops guest capture/contribution and removes it from the public program; clearly offer return to viewing without granting seller controls. | design-reference | T011, T025 |

| R025 | Ingest | Resolve the current event WHIP endpoint through an authorized adapter; select WHIP explicitly, never guess from RTMP/SRT/display text, and document the actual backend authorization contract. | integration-requirement | T014, T015, T036 |

| R030 | Lifetime | A separate studio owns media across console tab changes, console reload and navigation to another event; the studio stays bound to its original event and cannot silently retarget. | prototype-default | T017, T021 |

| R032 | PiP | Keep the live VDO.Ninja iframe and media ownership stable across float/return; do not reparent/reload a running iframe or create a second engine/camera/publisher during a UI transition. | prototype-default | T019, T020 |
| R033 | PiP | Closing/returning the PiP view restores controls/rendering to the studio and continues the same program within 1000 ms; the program frame producer must remain active while console interactions continue. | prototype-default | T019, T020, T034 |
| R034 | Lifetime | Handle blocked popups and studio stop/close/crash explicitly; closing PiP is not stopping output. Normal studio stop releases resources, and crash/lost-owner leases expire within 10000 ms. | prototype-default | T001, T021 |
| R035 | Recovery | Detect guest track/connection loss within 2000 ms then exclude its program media within another 1000 ms; reconnect returns to checks/backstage and requires a fresh admission. | prototype-default | T022, T026 |
| R036 | Devices | Handle host camera/mic loss or device switching with truthful state, a placeholder/silence and actionable recovery; restore capture only with appropriate consent, without duplicate live tracks. | prototype-default | T010, T033 |
| R037 | Recovery | Bound automatic output retries to three at 1, 2 and 4 seconds (jitter up to 20%); expose a stable fault and manual retry thereafter, preserve event binding and never auto-readmit a guest. | prototype-default | T015, T022, T023 |
| R038 | Connectivity | Demonstrate actual direct and forced-TURN relay contribution paths with selected candidate-pair evidence; simulated packet loss or a configured TURN URL is not relay proof. | prototype-default | T024 |
| R039 | Mobile | Support physical Android Chrome and iPhone Safari guest flows: permission grant, preflight, backstage, admission, self mute/camera and leave; emulation is not a substitute. | prototype-default | T025 |
| R040 | Mobile | Handle orientation/camera switching and foreground/background/lock transitions; on observed mute/end/suspension exclude the guest within 2000 ms, and require renewed readiness/admission after interruption. | prototype-default | T026 |
| R041 | Compatibility | For unsupported host capabilities, missing canvas capture or blocked guest embeds, explain the limitation and offer a safe supported-browser/direct-open path; do not fake a successful fallback. | prototype-default | T027, T038 |
| R042 | Messaging | Validate origin, source window, schema version, event/session IDs, sender capability, generation, request ID and sequence before applying studio/engine commands. Reject forged, cross-event and stale messages. | prototype-default | T028, T029 |
| R043 | Secrets | Keep real host authentication, ingest tokens and publish resources out of guest payloads/URLs, DOM-visible fields, persistent browser storage, analytics and exported logs; invite capabilities are short-lived and must be redacted in shareable evidence. | prototype-default | T003, T030 |
| R044 | Ordering | Make destructive and admission commands idempotent with acknowledgement and ordering; reject commands from previous generations after removal, replacement or reconnect. | prototype-default | T012, T029 |
| R045 | Origins | Use a documented exact-same-origin engine/media-access deployment or a verified explicit frame/audio bridge; iframe control alone and sibling subdomains do not grant parent access to video DOM/streams. | prototype-default | T013, T038 |
| R046 | Reproducibility | Pin the VDO.Ninja engine source/build, implementation revision and host browser versions in the build manifest/evidence; do not treat a changing alpha URL as a reproducible dependency. | prototype-default | T038, T039 |
| R047 | Diagnostics | Provide opt-in read-only redacted diagnostics for session/generation/program revision, admission, track counts, frame timestamps, output counters, owner/lease and fault state; no diagnostic action may bypass admission or authorization. | prototype-default | T028, T039 |
| R048 | Accessibility | Make all critical controls keyboard-operable with accessible names, status announcements and predictable focus; restore focus after PiP return/error and do not announce private messages publicly. | prototype-default | T031 |
| R049 | Responsive | Keep the guest journey usable at a 360x640 CSS viewport and the host console at 1280x720; avoid clipped controls, hidden buyer chat and horizontal overflow in critical controls. | prototype-default | T001, T032 |
